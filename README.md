# QuickSilver

Esse é um projeto pessoal em desenvolvimento para me ajudar no tracking de tarefas, notificações diretas no celular e no computador para lembrar de tarefas agendadas em background com uso de daemons.

Uso:
   quicksilver <nome_tarefa> <hora_inicio> <hora_fim>

  Exemplos:
    quicksilver "Estudar Ruby" 14:00 16:00
    quicksilver "Reunião" 10:30 11:00

  Opções:
    -h, --help    mostra esta mensagem
    -d, --daemon  passa processo para background
    --list/status lista tarefas
